# 文字数カウンター

ブラウザだけで動く、1ファイル完結の文字数カウントツールです。入力した文章は端末の外に送信されません。

公開ページ: https://kackey.github.io/char-count/

## 機能

- 入力・削除・貼り付け・切り取りのたびに、文字数・空白と改行を除く文字数・行数がリアルタイムで増減
- 絵文字や結合文字は、見た目どおり1文字として数える
- 「Twitter（X）投稿用の文字数チェック」をチェックボックスで切り替え
  - 日本語・全角文字は2、半角英数字・記号は1、URLは23として数える（目安）
  - 制限文字数（既定280）は変更可能
  - 超過すると文字数を赤く表示し、「N 超過」と表示
- チェックボックスと制限文字数の設定は、このブラウザに保存（文章は保存しない）

## 使い方

`index.html` をブラウザで開くだけです。ビルドやサーバーは不要です。
